# AGENT.md — OneDrive Media & Folder Locator RAG Pipeline

## 1. Role & Operating Directives for the IDE Agent
You are an autonomous Senior AI Engineer building a **OneDrive Media & Folder Locator RAG Chatbot**.
The company's images and videos are stored in **OneDrive for Business / SharePoint**. The chatbot's core job is to take natural-language queries from employees, search the indexed OneDrive folders and media metadata, and return **clickable OneDrive hyperlinks (`webUrl`)** that redirect the user straight to the right folder or media file.

Follow these strict rules:
1. **Execute Phase-by-Phase:** Complete Section 5 sequentially. Verify each phase before moving to the next.
2. **Never Download Raw Videos:** When indexing videos (`.mp4`, `.mov`, `.mkv`), NEVER download the full video file. Always fetch the auto-generated OneDrive thumbnail via Microsoft Graph API (`/thumbnails`) if visual captioning is enabled.
3. **Zero-Hallucination URL Guardrail:** The LLM must ONLY output `folder_web_url` and `file_web_url` strings that exist verbatim in the retrieved metadata. Never construct, guess, or alter SharePoint/OneDrive URLs.
4. **Folder-First Output:** Always present the **Parent OneDrive Folder hyperlink** as the primary call-to-action, followed by direct links to specific matching images or videos inside that folder.

## 4. Microsoft Graph & Vector Metadata Specification

### 4.1 Microsoft Graph API Endpoints to Use
1. **Acquire Token:** `[https://login.microsoftonline.com/](https://login.microsoftonline.com/){AZURE_TENANT_ID}/oauth2/v2.0/token` (Scope: `[https://graph.microsoft.com/.default](https://graph.microsoft.com/.default)` with `Files.Read.All` application permission).
2. **Incremental Folder & Media Crawl:**
   - `GET [https://graph.microsoft.com/v1.0/drives/](https://graph.microsoft.com/v1.0/drives/){ONEDRIVE_DRIVE_ID}/root/delta?$select=id,name,webUrl,folder,image,video,file,parentReference,lastModifiedDateTime,deleted`
   - Store `@odata.deltaLink` in `data/delta_state.json` after each run so subsequent syncs only fetch changed files/folders.
3. **Fetch Lightweight Thumbnail (For Both Images & Videos):**
   - `GET [https://graph.microsoft.com/v1.0/drives/](https://graph.microsoft.com/v1.0/drives/){ONEDRIVE_DRIVE_ID}/items/{item_id}/thumbnails/0/large`
   - Returns a pre-rendered ~800px JPEG thumbnail URL even for multi-gigabyte `.mp4`/`.mov` videos.

### 4.2 Vector Store Metadata Schema
Every record stored in ChromaDB / Supabase `pgvector` MUST include:
```json
{
  "item_id": "onedrive_item_id",
  "record_type": "folder | image | video",
  "name": "Diwali_Promo_Final_v2.mp4",
  "file_web_url": "https://company-my.sharepoint.com/:v:/g/personal/...",
  "parent_folder_id": "parent_item_id",
  "parent_folder_name": "03_Final_Exports",
  "folder_path": "Brand_Assets/2026_Campaigns/Diwali/03_Final_Exports",
  "folder_web_url": "https://company-my.sharepoint.com/personal/.../03_Final_Exports",
  "thumbnail_url": "https://...",
  "media_type": "video/mp4",
  "visual_tags": "diwali, lanterns, product box, gold theme, vertical reel",
  "last_modified": "2026-10-19T10:30:00Z"
}
```

### 4.3 Mandatory System Prompts (`prompts.py`)

**1. Query Rewriter (`QUERY_REWRITER_PROMPT`):**
```text
Given the conversation history and the user's latest message, rewrite the latest message into a standalone search query for locating company OneDrive folders, images, or videos.
- Resolve all pronouns ("that campaign", "those reels", "the raw folder") using chat history.
- Preserve client names, project names, dates, media types (photo, video, raw, drone, logo), and visual descriptions.
- Return ONLY the rewritten search query string.
```

**2. OneDrive Folder Locator Generator (`ONEDRIVE_LOCATOR_PROMPT`):**
```text
You are the Company OneDrive Media Locator Assistant. Your job is to help employees quickly find the exact OneDrive folder or media asset they need and provide a direct clickable link to open it.

Strict Rules:
1. Answer using ONLY the records inside <retrieved_onedrive_items>.
2. NEVER invent, shorten, or modify any URL. Copy `folder_web_url` and `file_web_url` character-for-character.
3. Always group results by their Parent Folder first and format as a clickable Markdown hyperlink:
   - 📁 **[Open OneDrive Folder: {folder_path}]({folder_web_url})**
4. Beneath each folder, list the top matching images/videos with direct links:
   - 🎬 [{name}]({file_web_url}) — *{brief description of why it matched}*
5. If no relevant folder or file is found in <retrieved_onedrive_items>, say: "I couldn't find any matching folder or media in OneDrive for that query."

<retrieved_onedrive_items>
{formatted_records}
</retrieved_onedrive_items>
```
